All ready-to-run examples live in [anyserve.universe](https://github.com/anyserve/anyserve.universe). None of them are baked into the `anyserve` binary: every inference worker and host integration speaks the standard Python SDK (`anyserve-runtime`) over outbound-only gRPC or WebSocket (`wss://`).

```text
  ComfyUI Custom Nodes ───┐                                       ┌── openai/worker.py  (vLLM, Ollama, llama.cpp, SGLang)
  ROS 2 Nodes (Jazzy) ────┼──▶ AnyServe Control Plane ◀───────────┼── triton-inference-server/worker.py (Triton KServe v2)
  OpenAI HTTP Proxy ──────┤        (gRPC / wss://)                ├── yolo/worker.py    (Ultralytics YOLO)
  CLI / Python Clients ───┘                                       └── vla/worker.py     (LeRobot SmolVLA)
```

## Clone & prerequisites

```bash
git clone https://github.com/anyserve/anyserve.universe.git
cd anyserve.universe
pip install anyserve-runtime
```

Start a local authenticated control plane (or use the hosted demo at [anyserve.arcosx.org/tokens](https://anyserve.arcosx.org/tokens)):

```bash
anyserve serve --console-listen 127.0.0.1:3001 --auto-token
```

Every worker follows the same conventions:
- Registers `@worker(interface="<family>/<model>")` so each model has isolated queues, metrics, and routing policies.
- Accepts `--endpoint`, `--pool`, and repeatable `--attr KEY=VALUE` for placement (`required_attributes` / `preferred_attributes`).
- Reports transient backend failures (unreachable, HTTP 429, HTTP 5xx) with `WorkerError(..., retryable=True)` and fails invalid inputs fast without retrying.

## Measured overhead

Measured on a single Tesla T4 (client, control plane, worker, and backend on the same host; "Direct" bypasses AnyServe):

| Example | Backend and workload | Direct | Through AnyServe |
|---|---|---|---|
| `openai/` | vLLM, Qwen2.5-0.5B-Instruct, 32 tokens, 32 callers | 95.4 req/s, p50 338 ms | 93.9 req/s, p50 335 ms |
| `openai/` | Same, streaming TTFT | 19.5 ms | 19.7 ms |
| `triton-inference-server/` | MiniLM cross-encoder (ONNX Runtime), 8 callers | 1,546 req/s, p50 5.2 ms | 1,335 req/s, p50 5.9 ms |
| `yolo/` | YOLO11n on 640×480 video, 1 camera | 71 fps, 14.0 ms/frame | 62 fps, 15.6 ms/frame |
| `vla/` | SmolVLA on SO-100 pick-and-place episode at 30 Hz | 585 ms/inference | 588 ms/call |

AnyServe adds roughly **1 to 3 ms** per call on top of the inference backend.
